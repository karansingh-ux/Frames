# Frames — Official Website

The official landing page for **Frames**, a lightweight macOS screenshot utility.

## Tech Stack
- **Framework:** Vite 6 + TypeScript + Tailwind CSS
- **Icons:** Lucide Icons (Tree-shaken)
- **Typography:** Sen (Google Fonts)
- **Styling:** Custom minimal dark theme (`#08080C`)

## Development

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
```

Outputs static distribution files to `dist/`, ready for zero-config deployment on Vercel, Cloudflare Pages, Netlify, or GitHub Pages.
