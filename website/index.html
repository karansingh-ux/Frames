Frequently Asked Questions

Everything you need to know.

macOS requires any application using the modern ScreenCaptureKit API to have Screen Recording permission granted in System Settings. Frames processes all capture frames locally in-memory and never transmits any data outside your device.
When you take a screenshot, it remains accessible in the bottom-right preview stack for 60 seconds. If you click Copy, it writes to clipboard and dismisses immediately. If you leave it un-actioned, it will automatically save to ~/Desktop at t = 60s so you never lose work.
Frames is compiled as a Universal 2 binary supporting both Apple Silicon (M1, M2, M3, M4) and Intel x86_64 Macs. It is optimized for macOS 13.0 (Ventura), macOS 14.0 (Sonoma), and macOS 15.0+ (Sequoia).
macOS default thumbnails vanish in 5 seconds and forcibly dump files onto your Desktop. Frames holds captures for 60 seconds in a multi-stack of up to 5 items, allowing you to copy directly to clipboard with zero desktop clutter.
