Built for everyday speed.

No background library, no database, no accounts. Just immediate screenshot utility.

5-Card Temporary Stack

Takes up to 5 screenshots in succession without dumping files. Hover over the corner to fan out cards and pick what you need.

Copy vs. Save Invariant

Copy writes strictly to clipboard with 0 disk traces. Save writes directly to Desktop with clean standard naming.

60s Auto-Save Safety Net

Un-actioned captures stay available for a full minute before safely auto-saving to Desktop so you never lose work.

Scrolling Capture

Auto-scrolls and stitches long web pages, code files, and chat threads directly into an expanded viewer.

Configured exactly as it appears inside the macOS app.
